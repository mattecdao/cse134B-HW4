# cse134B-HW4

## Repetitiveness
For me, I found the process of creating each new part of the website to be repeated by hand. Since each page had a new layout, each style was taken from the respective layout demo and extended upon. The only exception of this was for the cheese families which shared the same CSS style. Nevertheless, even though the majority of the sites contained very similar structure (same <head>, header, nav, main, footer), they all had to be adjusted for their respective purposes meaning I had to adjust titles, descriptions, etc... by hand as well.

## Broken URLS
I initially confused when I started to work on and test the nav links for sites in the guide folder. I then realized the URL path had to be adjusted to match the folder change. This was sort of a hassle since it got in the way of me making the layouts (styles wouldn't work for the demo and on pages I was working on). Furthermore, there were times where I was taken off guard by these paths and ran into bad link errors. For instance, I would copy and paste my <nav> and <footer> content since they are the same for each page. However, I would forget the URL's in each <a> tag get broken if pasted to the guide folder.
